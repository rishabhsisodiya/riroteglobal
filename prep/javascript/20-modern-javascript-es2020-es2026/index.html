Modern JavaScript (ES2020 → ES2026)

Last reviewed 6 Sept 2026

JavaScript ships a new ECMAScript edition every June. This page tracks what landed recently and what’s next. To update it: check the finished proposals at tc39/proposals and the Stage-3 list at tc39.es, then add a section below (newest first).

Everything from ES2020 onward is safe to use in evergreen browsers and current Node without a transpile step. Interviewers increasingly expect familiarity with at least ES2020–ES2023; Temporal and using are the 2025–26 talking points.

ES2026 — shipping now

The 17th edition. Reached Stage 4 in early 2026.

Temporal API — the Date replacement

Immutable, timezone- and calendar-aware date/time. Fixes almost every Date foot-gun (mutability, month indexing, parsing, timezone math).

Explicit resource management — using / await using

Deterministic cleanup, no try/finally. The resource must implement Symbol.dispose (or Symbol.asyncDispose).

Array.fromAsync()

Builds an array from an async iterable — the for await loop you kept writing by hand.

Error.isError()

Reliable cross-realm error check (survives iframes / worker boundaries where instanceof Error fails).

ES2025

16th edition, approved June 2025.

Iterator helpers

Lazy .map / .filter / .take / .drop / .flatMap / .reduce directly on any iterator — no [...spread] to an array first.

Set methods

Promise.try()

Runs a function and always returns a promise — sync throws, sync returns, and async results all funnel through one .catch.

JSON modules

RegExp.escape()

Escape a string for safe use inside a dynamic RegExp.

Also in ES2025

  • Float16Array — 16-bit float typed array (ML, graphics, WebGPU).
  • Regex pattern modifiers — (?i:...) / (?-i:...) to toggle flags for part of a pattern.
  • Duplicate named capture groups across alternation branches.

ES2024

Object.groupBy() / Map.groupBy()

Promise.withResolvers()

Get a promise plus its resolve / reject without the callback-closure dance.

Also in ES2024

  • String.prototype.isWellFormed() / toWellFormed() — detect / fix lone surrogates.
  • RegExp v flag — set notation and string properties in character classes.
  • ArrayBuffer.prototype.resize() / transfer() — resizable and transferable buffers.
  • Atomics.waitAsync() — non-blocking wait on shared memory.

ES2023

Change array by copy

Non-mutating versions of the four mutating array methods:

findLast() / findLastIndex()

Also in ES2023

  • Symbols allowed as WeakMap keys.
  • Hashbang (#!/usr/bin/env node) is now part of the grammar.

ES2022

  • Top-level await in modules — no async IIFE wrapper for entry points.
  • Class fields, #private fields and methods, static {} init blocks.
  • Array.prototype.at() / String.prototype.at() — arr.at(-1) for the last item.
  • Object.hasOwn(obj, key) — the safe replacement for obj.hasOwnProperty(key).
  • error.cause — new Error('failed', { cause: originalError }).
  • RegExp d flag — match start/end indices via match.indices.

ES2021

  • String.prototype.replaceAll() — no more /g regex just to replace all.
  • Promise.any() — first fulfilled wins; rejects with an AggregateError only if all fail.
  • Logical assignment — a ??= b, a ||= b, a &&= b.
  • Numeric separators — 1_000_000, 0xFF_EC_DE.
  • WeakRef / FinalizationRegistry — advanced, rarely needed.

ES2020

The baseline for “modern JS”.

  • Optional chaining — user?.profile?.avatar.
  • Nullish coalescing — value ?? fallback (only null/undefined, unlike ||).
  • Promise.allSettled() — wait for all, never short-circuit on rejection.
  • BigInt — arbitrary-precision integers: 9007199254740993n.
  • globalThis — one name for the global object across browser / Node / worker.
  • Dynamic import() — const mod = await import('./heavy.js').
  • String.prototype.matchAll(), import.meta, stable Array.prototype.sort.
