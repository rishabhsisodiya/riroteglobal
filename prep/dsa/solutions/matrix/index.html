Spiral traversal of a matrixMedium1 approach

Also asked as: Spiral traversal on a Matrix

1. Shrinking boundaries

Time O(R·C)Space O(1) extra

Keep top/bottom/left/right walls; walk right, down, left, up, moving the wall in after each pass.

Search an element in a matrixMedium2 approaches

Also asked as: Search an element in a matriix

1. Staircase search (rows & columns sorted)

Time O(R + C)Space O(1)

Start at the top-right. If it is bigger than target move left, if smaller move down. Each step eliminates a row or column.

2. Binary search (fully sorted, row-major)

Time O(log(R·C))Space O(1)

Treat the R·C cells as one sorted array; map index → (row, col).

Median in a row-wise sorted matrixHard1 approach

Also asked as: Find median in a row wise sorted matrix

1. Binary search on the value

Time O(R · log C · log(range))Space O(1)

For a candidate value, count how many cells are ≤ it (binary search per row). The median is the smallest value with count ≥ (R·C+1)/2.

Row with the maximum number of 1sEasy1 approach

Also asked as: Find row with maximum no. of 1's

1. Staircase from top-right

Time O(R + C)Space O(1)

Each row is sorted (0s then 1s). Move left while the current cell is 1; every time you can, that row has more 1s.

Print elements in sorted order (row- and column-sorted matrix)Medium1 approach

Also asked as: Print elements in sorted order using row-column wise sorted matrix

1. Min-heap of row frontiers (merge k sorted lists)

Time O(R·C · log R)Space O(R)

Each row is sorted; push the first cell of every row into a min-heap, pop the smallest, and push the next cell from that row.

Shown with a sorted array for brevity; a real binary min-heap makes each push/pop O(log R).

Maximum size rectangle of 1s in a binary matrixHard1 approach

Also asked as: Maximum size rectangle

1. Row-by-row histogram + largest rectangle in histogram

Time O(R·C)Space O(C)

For each row, build a histogram of consecutive 1s upward, then run the O(n) stack-based "largest rectangle in histogram" on it.

Maximum value of a[c][d] − a[a][b] with c > a and d > bMedium1 approach

Also asked as: Find a specific pair in matrix

1. Suffix max of the bottom-right submatrix

Time O(n²)Space O(n²)

maxFromBelowRight[i][j] = max over the submatrix below and right of (i,j). Answer = max(maxFromBelowRight[i+1][j+1] − a[i][j]).

Rotate a matrix by 90 degreesMedium1 approach

Also asked as: Rotate matrix by 90 degrees

1. Transpose, then reverse each row

Time O(n²)Space O(1)

Transposing swaps rows/columns; reversing each row then gives a clockwise 90° rotation. In place.

Counter-clockwise: reverse each row first, then transpose (or reverse the row order after transpose).

Kth smallest element in a row- and column-sorted matrixMedium1 approach

Also asked as: Kth smallest element in a row-cpumn wise sorted matrix

1. Binary search on the value

Time O(n · log(range))Space O(1)

Count cells ≤ mid with a staircase walk (O(n)). The answer is the smallest value whose count ≥ k.

Common elements in all rows of a matrixMedium1 approach

Also asked as: Common elements in all rows of a given matrix

1. Frequency map seeded by the first row

Time O(R·C)Space O(C)

Put row 0 in a map (value → 1). For each later row, bump a value only if its stored count equals the current row index. At the end, values with count === R are common to all.
