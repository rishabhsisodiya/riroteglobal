Bit Manipulation

9 problems · 10 approaches

← Checklist · All topics →

Count set bits in an integerEasy2 approaches

Also asked as: number of 1 bits · count total set bits

1. Kernighan’s trick

Time O(set bits)Space O(1)

`n & (n - 1)` clears the lowest set bit; count how many times you can do it.

2. Shift and mask

Time O(32)Space O(1)

Check the last bit, shift right, repeat 32 times.

Find the two non-repeating elements (all others appear twice)Medium1 approach

Also asked as: Find the two non-repeating elements in an array of repeating elements

1. XOR everything, split by a differing bit

Time O(n)Space O(1)

XOR of the whole array = x ^ y. Any set bit in it differs between x and y — partition the array by that bit and XOR each group separately.

Count bits to flip to convert A to BEasy1 approach

Also asked as: Count number of bits to be flipped to convert A to B

1. Popcount of A XOR B

Time O(bits)Space O(1)

A ^ B has a 1 exactly where the bits differ.

Count total set bits in all numbers from 1 to nMedium1 approach

Also asked as: Count total set bits in all numbers from 1 to n

1. Per-bit contribution

Time O(log n)Space O(1)

For bit position b, the bit cycles with period 2^(b+1): 2^b zeros then 2^b ones. Count full cycles × 2^b plus the partial remainder.

Check whether a number is a power of two / find the position of its only set bitEasy1 approach

Also asked as: Program to find whether a no is power of two · Find position of the only set bit

1. n & (n − 1)

Time O(log n)Space O(1)

A power of two has exactly one set bit, so n & (n−1) clears it to 0. The bit position is log2(n), or count right shifts until you reach 1.

Copy set bits in a given range from one number to anotherEasy1 approach

Also asked as: Copy set bits in a range

1. Build a range mask and OR

Time O(1)Space O(1)

mask = bits [l..r] set. result = x | (y & mask) — copies y’s bits in that range into x.

Divide two integers without *, / or %Medium1 approach

Also asked as: Divide two integers without using multiplication, division and mod operator

1. Repeated doubling of the divisor

Time O(log² n)Space O(1)

Subtract the largest shifted copy of the divisor (divisor << k) that still fits; add 2^k to the quotient. Handle signs and the INT_MIN edge case.

Square a number without *, / or pow()Easy1 approach

Also asked as: Calculate square of a number without using *, / and pow()

1. n² = sum of the first n odd numbers

Time O(n)Space O(1)

1 + 3 + 5 + … + (2n−1) = n². Add n odd numbers.

O(log n) via bit shifts: square(n) = (square(n>>1) << 2) + (n odd ? (n<<1) - 1 : 0).

Power set of a setEasy1 approach

Also asked as: Power Set

1. Bitmask enumeration

Time O(2ⁿ · n)Space O(1) extra

Every subset ↔ a number 0..2ⁿ−1; bit j set means element j is included.
