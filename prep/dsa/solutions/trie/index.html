Construct a trie (insert / search / startsWith)Medium1 approach

Also asked as: Construct a trie from scratch

1. Nodes with a children map and an end flag

Time O(L) per opSpace O(total chars)

Each node holds a map char→child and a boolean "is a word end". Insert/search/prefix all walk character by character.

Shortest unique prefix for every wordMedium1 approach

Also asked as: Find shortest unique prefix for every word in a given list

1. Trie with per-node pass-through counts

Time O(total chars)Space O(total chars)

Insert all words, storing at each node how many words pass through it. For each word, the shortest unique prefix ends at the first node whose count is 1.

Word Break (trie solution)Medium1 approach

Also asked as: Word Break Problem | (Trie solution)

1. DP over prefixes, dictionary stored in a trie

Time O(n² ) worst, faster in practiceSpace O(dict)

dp[i] = s[0..i) is breakable. From each true dp[j], walk the trie along s[j..] and set dp[k] wherever you hit a word end.

Implement a phone directory (prefix search)Medium1 approach

Also asked as: Implement a Phone Directory

1. Trie; DFS from the prefix node to list matches

Time O(L + matches)Space O(total chars)

Insert all contacts. For each successive prefix of a query, find its trie node and DFS to collect all words below it.

Print unique rows in a boolean matrixEasy1 approach

Also asked as: Print unique rows in a given boolean matrix

1. Trie of rows (or a set of joined strings)

Time O(rows · cols)Space O(rows · cols)

Treat each row as a binary string; insert into a trie (or a Set). Print a row only the first time it is inserted.
