React 19

Last reviewed 6 Sept 2026

React 19 shipped in December 2024. It builds on React 18’s concurrent renderer and makes several long-standing patterns unnecessary.

The “React 18 updates” chapter is still relevant — createRoot, automatic batching, useTransition, useDeferredValue, useId and Suspense all carry forward. This chapter is only the deltas.

use() — read a promise or context during render

use() is a new API (not a hook — it can be called conditionally and in loops) that unwraps a promise or reads a context.

The promise should be created by a framework/cache, not inside render, so it isn’t recreated every time.

Actions and the new form hooks

An Action is an async function passed to <form action={...}> (or called from an event) that React tracks for pending state, errors, and optimistic updates.

useActionState

Wraps an action and gives you its return value, a bound action, and a pending flag.

useFormStatus

Lets a nested component (e.g. a submit button) read the parent form’s pending state without prop-drilling.

useOptimistic

Show an optimistic value immediately while an action is in flight; React reverts it if the action fails.

ref as a regular prop — no more forwardRef

Function components now accept ref directly in props.

forwardRef still works but is deprecated; a codemod migrates it. Refs also support a cleanup function returned from the ref callback.

Document metadata hoisting

<title>, <meta> and <link> rendered anywhere in the tree are automatically hoisted into <head> — no more react-helmet for basic cases.

Stylesheets and async scripts rendered in components are also deduped and ordered.

Other changes

  • <Context> as a provider — <ThemeContext value={theme}> instead of <ThemeContext.Provider value={theme}>.
  • Better error reporting — hydration mismatches show a single diff; onCaughtError / onUncaughtError root options.
  • ref cleanup, useDeferredValue initial value, and Suspense sibling pre-warming.
  • Removed: legacy ReactDOM.render, hydrate, string refs, defaultProps on function components (use default parameters), legacy context (contextTypes), propTypes (they’re ignored — use TypeScript).

The React Compiler

An optional build-time compiler (Babel/SWC plugin) that automatically memoises components and values, so you rarely need useMemo / useCallback / React.memo by hand. It relies on you following the Rules of React (no mutation during render, pure components). Adopt it incrementally per directory; it’s independent of the React 19 runtime.
